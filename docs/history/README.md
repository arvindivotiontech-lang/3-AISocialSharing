# History Documentation (Archived)

> **Authority:** Historical reference only. Not current requirements.
> Always check `../stable/` for what is currently approved.

## Purpose
Preserve previous Stable versions, unmodified, whenever a new Stable
release is approved.

## Structure
Archived snapshots are stored as `releases/v<version>/`. Create a release
folder only when that release actually exists and is being superseded.

## Rules
- Preserve the previous stable release as an unmodified snapshot.
- Retain its version number, release date, approval information, and release notes.
- Record what changed and why in the release log below.
- Treat archived documents as read-only.
- Do not use historical requirements as current requirements without
  checking the latest Stable documentation.
- Do not delete historical records as part of routine cleanup.
